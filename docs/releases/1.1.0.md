# DuoDeck 1.1.0

A simpler native control experience for iPhone, iPad and Mac.

- New DuoDeck icon, restrained teal identity and adaptive light/dark UI.
- A compact control deck with persistent trackpad sizes, useful shortcuts and a dedicated Controls sheet.
- Advanced streaming and connection options grouped behind native settings.
- A clearer Mac Overview with setup, pairing and device actions.
- Matching Smooth, Balanced and Crisp profiles across the native apps.
- Corrected action labels, help links, release destinations and inherited visible branding.
- A new product website with an accessible interactive preview.

The Mac companion requires macOS 14 or later. This release includes signed and notarized Mac downloads and their SHA-256 checksums. iOS source is included in the tagged repository; App Store upload, processing, review and availability are separate provider states.

DuoDeck builds on the Apache 2.0 licensed Sill engine. Original attribution and license are retained.
