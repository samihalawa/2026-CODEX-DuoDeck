# DuoDeck 1.1.0 verification checkpoint

Observed on 9 November 2026. This checkpoint covers the branding redesign, regular Mac application lifecycle, and capture/first-picture recovery changes. See [the current release record](../duodeck-app-store-release.md) for the later Mac publication and iOS review submission.

## Product and source

The website leads with “Control your Mac from your iPhone or iPad.” It uses Instrument Sans, white and grey surfaces, one blue action color, a plain wordmark and an interactive browser preview. Setup has three steps and explains that both native apps are required. The current Dock-app copy passes all 10 web checks. Production HTTPS health and homepage readback at 17:25:38 UTC confirm deployed implementation source `0bda6694a6ce0ca45f95242b7a5e9c751f9aa6f0` and both updated Dock-app descriptions.

iOS starts with Macs and Add Mac, followed by Scan code or Enter code and Pair Mac. Working screens keep Apps, Keyboard, Shortcuts and Settings accessible. New installations use the Medium upright trackpad and hide the optional shortcut row; saved choices are retained. System lists, forms, navigation and semantic colors carry the interface.

DuoDeck Host is a regular Mac app with a Dock/app-switcher icon, a resizable window, standard window controls and Dock reopening. Closing its window keeps the host running; Quit stops it. General, Devices, Streaming and Advanced preserve existing saved routes. Screen Recording and Accessibility requests occur only through explicit user actions.

Capture connectivity and picture readiness are separate. Native capture failures now produce actionable messages and Retry picture. Lookup has a bounded, cancellation-safe timeout; initial picture recovery has a three-request budget. Late display attachment replays a keyframe only when no dependent frames were missed. Current-generation decoder readiness, source retry and lock precedence are covered by focused checks.

Both native icons use the same paired-D artwork, with a matching Mac menu template glyph. Visible permission, connection, lock and keychain fallback copy uses DuoDeck. Protocol identifiers, stored pairings and keychain names remain compatible. Original Sill license and attribution remain intact. The design direction and reusable execution prompt are in [PRODUCT_BRIEF.md](../PRODUCT_BRIEF.md).
