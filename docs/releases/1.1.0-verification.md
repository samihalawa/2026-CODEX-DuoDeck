# DuoDeck 1.1.0 verification checkpoint

Observed on 9 November 2026. This is a dated release checkpoint, not a claim that Apple has approved or published the apps. Current provider records take precedence.

## Product and source

The redesign uses one DuoDeck icon and the tagline “Your Mac. In your hands.” across the native connection screen, compact deck, app icons, website and store metadata. The native apps use system controls, adaptive light/dark surfaces and restrained teal accents. Everyday controls stay on the main surface; detailed streaming, connection and diagnostic options live in native settings and submenus.

Ordinary iPhone, iPad and Duo layouts share persistent Small, Medium and Full trackpads and useful shortcut groups. Pointer speed and haptics affect the actual controls. Both native platforms provide the same Smooth, Balanced and Crisp streaming presets. The Mac menu has seven primary items, with Quality and Advanced submenus and an Overview for setup and paired devices.

Product direction and the reusable professional execution prompt are in [PRODUCT_BRIEF.md](../PRODUCT_BRIEF.md). Original Sill license and attribution remain intact; compatibility identifiers were retained where changing them would disrupt protocol or pairing state.

## Publication sequence and limits

Publish the exact verified Mac artifact only after Apple returns Accepted, its tickets are stapled and validated, Gatekeeper accepts the app, and the published bytes match the generated checksums. Then submit the existing iOS review draft and verify its native submitted date and state. A ready draft is not a sent review request; a sent request is not approval or public availability.

The final pre-staple DMG SHA-256 is `2d4efb12639385e20fa7c34d5487dafefc322dca18dc55b46cf32f5a984ec420`. The final uploaded IPA SHA-256 is `0789a686f3464e5eb9693d421fb8e90edbb85028262e3c8e9ff4b3922069cd8f`. Stapling changes the DMG bytes; the published checksum must be generated afterward.

Mac4's normal Keychain access prompt requires local approval. The system denied remote UI input, so end-to-end live streaming on that installation has not been verified. Existing pairing keys were preserved. The legacy Keychain item's old display label may still appear in that OS prompt; new items use DuoDeck Remote Access.

No mobile-browser viewport review is claimed. Native phone and iPad layouts were inspected. Android, Windows, a sandboxed Mac App Store client, hosted accounts and paid entitlements are outside the existing shipping implementation and have not been released.
