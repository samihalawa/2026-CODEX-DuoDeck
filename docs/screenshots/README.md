# DuoDeck website preview

`website.jpg` is a JPEG export of the redesigned local website rendered in the existing Mac4 Chrome session on 9 November 2026. It captures the actual implementation at 1440 × 1000 pixels, before production redeployment. It replaces the earlier teal, folded-device illustration.

The Notes window is explicitly labeled as an example and the interactive controls are labeled Browser preview. This is not a live Mac streaming session. Pointer drag/tap, keyboard control, checklist hit testing, settings persistence, shortcut groups, reset and focus restoration were exercised separately in the browser.

The page was also rendered at 320px, 390px and 800px widths and in dark appearance. Mobile settings and download sections were visually inspected without horizontal overflow.
