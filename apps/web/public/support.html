DuoDeck Support

Setup, pairing & troubleshooting

DuoDeck connects your iPhone, iPad, or iPhone Duo directly to DuoDeck Host running on your Mac. Free local control requires no account or subscription.

1. Mac permissions required

Open DuoDeck Host from your Mac Dock and grant both permissions when prompted:

  • Screen Recording (System Settings › Privacy & Security › Screen & System Audio Recording): lets DuoDeck stream a chosen Mac window or desktop. Reopen DuoDeck Host if macOS asks to apply the permission.
  • Accessibility (System Settings › Privacy & Security › Accessibility): lets DuoDeck deliver pointer movement, clicks, scrolling, keyboard typing, and shortcuts.

2. Pairing & Local Network discovery

Keep both devices on the same Wi-Fi network (or connect over USB) and keep your Mac awake:

  • On iPhone or iPad, allow Local Network access (Settings › Privacy & Security › Local Network › DuoDeck).
  • Open Macs › Add Mac, then scan the pairing QR code from the Mac menu bar (Pair iPhone or iPad…) or choose Enter code to type the Mac address and 12-digit pairing code manually without camera access.
  • If macOS Application Firewall blocks incoming connections, allow DuoDeck Host in System Settings › Network › Firewall.

3. Floating Keyboard & iPhone Duo Back Screen

  • Floating Keyboard: open View › Keyboard › Floating (drag anywhere) to drag a translucent Mac keyboard anywhere on screen, resize from the bottom-right handle, and switch ABC / 123 / #+= layers with Esc, Tab, Control, Option, Command, Shift, and arrow keys.
  • iPhone Duo Back Screen: while DuoDeck is active on the inner display, enable Back screen to show Mirror Mac, Mirror · Fill Screen, Trackpad, or Zoom on the outer cover screen. Note that iOS reserves the outer display exclusively while DuoDeck is the foreground app; switching to another app yields the outer display.
