Questions

Quick answers

Is local Mac control really free?

Yes. Direct Wi-Fi and USB pairing between your iPhone/iPad and Mac requires no account, no subscription, and no paywall.

Why do I need DuoDeck Host on my Mac?

macOS requires user-approved Screen Recording and Accessibility permissions inside a local host app to capture windows and inject pointer or key events.

Can I use it over USB as well as Wi-Fi?

Yes. Connect on the same local Wi-Fi network or over a direct USB cable connection with automatic Bonjour discovery or 12-digit code entry.
